# NetworkFabric controller

Reconciles cluster-scoped `NetworkFabric` resources into Talos VLAN/bridge configuration one node at a time. Talos changes are applied with `--mode=try`, management interfaces are revalidated before confirmation, and the controller periodically rechecks node capabilities and migration-network compatibility.

The controller requires an `os:admin` Talos client configuration in a Secret. By default the chart reads key `talosconfig` from Secret `network-fabric-talosconfig` in the release namespace. The Secret is intentionally not generated by the chart.
